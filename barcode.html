Preguntas frecuentes

¿Qué formato debo usar?

EAN-13 para productos de venta al público (supermercados, bodegas). Code 128 para uso interno, logística y códigos con letras. ITF-14 para cajas de embalaje. UPC para productos que se venden en EE. UU.

¿Puedo inventar un código EAN-13?

Para uso interno sí. Para vender en cadenas de supermercados necesita códigos oficiales asignados por GS1 de su país.

¿Por qué me dice que el valor no es válido?

EAN-13, UPC e ITF-14 solo aceptan números con una cantidad exacta de dígitos y un dígito de control. Si escribe 12 dígitos en EAN-13, el dígito de control se calcula solo.

¿Cómo imprimo muchas etiquetas?

Use el generador masivo con un Excel, o nuestra plantilla de inventario.
