Cómo se usa, paso a paso

  1. Suba su PDF. Verá una miniatura de cada página.
  2. Elija qué hacer. Extraer las páginas que toque o escriba (ej.: 1-3, 5), separar todas o dividir cada N páginas.
  3. Descargue. Un PDF con las páginas elegidas, o un ZIP con todos los archivos.

Preguntas frecuentes

¿Cómo escribo las páginas?

Use comas para páginas sueltas y guiones para rangos. Por ejemplo, 1-3, 5, 8-10. Escriba 7- para ir desde la 7 hasta el final.

¿Se pierde calidad?

No. Las páginas se copian tal cual: el texto sigue siendo seleccionable y las imágenes no se modifican.

¿Puedo cambiar el orden de las páginas?

Al extraer, las páginas se guardan en el orden en que las escribe. Por ejemplo, 3, 1, 2 crea un PDF con la página 3 primero.
